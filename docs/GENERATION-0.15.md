# AI 生成资料（0.15）

## 入口与流程

人物卡、背包与账本、人物关系、场景与时间、剧情档案中都有 **AI 生成／补充**。世界状态 → 联动更新中另有 **联合初始化**，可一起建立相互关联的资料。

1. 展开入口，选择本次生成的应用范围。需要先建立人物时，一起勾选人物卡。
2. 选择生成方式：仅新增、补充缺项、按剧情更新。
3. 勾选需要读取的角色卡、用户设定、世界书或聊天楼层，也可填写具体要求。来源默认不勾选；世界书只读明确选择的书，不会自动扩大到全库。
4. 生成后检查建议，修改字段，取消不想采用的项目。
5. 点击“预览所选变更”，核对前后内容，然后“确认保存整组资料”。仅生成或预览不会改动数据。

减少采用项目后，依赖也需要完整。例如，某件物品属于新人物，取消建立该人物后，物品建议也应取消或改绑到已有的人物 ID。验证失败时整批不写入。

## 三种方式

| 方式 | 行为 |
| --- | --- |
| 仅新增 | 建立新记录，保留已有资料；不会清空应用重建。 |
| 补充缺项 | 填补空字段或添加新记录；已有文字、数值、0 和 false 均受保护。遇到覆盖建议会拒绝，并提示改用更新模式。 |
| 按剧情更新 | 按选定来源修改资料。变更仍须经过预览确认，不自动执行删除、消费、转账或效果结算操作。 |

生成器读取所选应用的当前资料以便去重，并读取关联所需的人物名称和 ID、可见地点、现有数值绑定。人物属性继续引用世界状态；没有对应数值字段时，应先在世界状态建立字段，再补充人物绑定。

剧情档案的事实、记忆、伏笔和编年史需要真实的来源楼层。没有选择聊天楼层时，联合生成会明确跳过档案；仅生成档案时会提示补选来源。编年史结果进入待审核草稿，仍须在剧情档案确认。

## 渠道与预设

在 AI 设置 → 应用渠道中设置对应应用：

- 只勾选一个应用：使用该应用的渠道与参数。
- 同时勾选多个应用：使用“联合初始化”渠道。
- “酒馆当前配置 · 完整预设”由酒馆通过 Quiet 组装完整预设；指定连接配置与独立 API 继续使用现有渠道流程。

显式选择来源控制 Amin 提交的工具任务。完整酒馆预设仍可能自行加入历史、世界书和其他扩展内容；它的最终上下文由酒馆控制。

## 保存与原有功能

手动生成不要求开启统一联动，也不会打开后台自动更新或改动原有读取、写入开关。关系的“分析所选剧情”和编年史原有的 AI 草稿入口继续保留。

生成期间切换聊天、修改正文或关联资料，旧结果会失效。确认时重新核对选定来源；来源已修改时需重新生成。保存失败后使用“重试保存生成资料”，避免重复生成和应用同一批次。

验证使用自动测试及隔离模拟宿主，模型输出可由测试替身提供；这些检查不代表实际供应方、酒馆版本或实体手机已验证。
