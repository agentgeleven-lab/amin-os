# 应用 API 渠道

1. 在 AI 设置 → API 连接中填写接口，保存为新配置。每份配置可使用不同模型和自定义 requestBody。
2. 在 AI 设置 → 应用渠道中，为地图、世界状态、回复选项、文风转换（合并应用的改写任务）、势力概览、能力面板、信息面板分别选择配置；选择后自动保存。
3. 选择“跟随全局默认”恢复共用设置。

回复选项与文风转换仅合并界面，候选生成和草稿改写仍保留各自原有渠道，不覆盖已保存配置。

信息面板的资料生成和模拟推演共用其渠道。异步预设仍共用；已开始的任务固定使用开始时的配置。任务记录可查看渠道名。

更新已保存的配置影响绑定该配置的应用；删除配置后相关应用恢复全局默认。仅修改全局设置不会改写已保存的独立配置。选择配置编辑时会将它载入全局设置，沿用现有操作方式。

密钥默认仅在本次页面会话中保留，需要跨重启保存时勾选“记住密钥”。应用绑定只存配置 ID，不复制密钥。

语音朗读使用独立语音协议，其 MiMo、火山引擎与本地服务在语音应用内设置；世界书管理不调用生成 API。
