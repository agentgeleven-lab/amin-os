# Amin os 0.7.1

将动态地图、世界状态栏和回复选项整合为一个 SillyTavern / TauriTavern 前端扩展。

默认在右下角显示可拖动的 Amin os 小入口。点击向上展开侧栏，首页有可整理的应用磁贴，通过返回键回到开始屏。收起和切换应用保留当前页面；刷新时默认收起。拖动入口后记住位置，支持方向键移动、Escape 收起；靠近屏幕顶部时向下避让，保证应用内容和入口可见。

## 0.7.1 自定义主页磁贴

主页 → 编辑布局：每块磁贴可以选择打开的应用、自定义名称和尺寸。可以新增、复制、删除或撤销最近一次删除，同一应用可配置多个入口。拖动排序和前移/后移保留。重复磁贴打开同一应用页面，共享该应用的数据，不创建独立副本。

旧布局自动迁移并保留顺序与尺寸；新布局保存到本设备浏览器，删除的磁贴不会刷新后重新出现。主页下方「所有应用」始终可以进入各应用，即使已删光磁贴也可继续使用和新增。设置中可恢复默认磁贴布局。

## 0.7.0 独立信息面板

新增人物、事物、世界三类资料面板，沿用 OS 统一主题、按钮、表单与磁贴布局。与能力应用分别存储，不直接改动世界书、地图或状态栏。

- 在「生成资料」填写目标和要求，选择「酒馆资料」「互联网」或「两者」。酒馆来源可选择当前可用的世界书、角色卡和聊天；先刷新世界书列表。AI 规划关键词后检索相关片段，并显示检索范围、来源和未纳入数量。资料预算有限，不保证查全所有信息。
- 默认只整理来源；勾选允许创作补全后，可按要求生成资料里没有的设定。字段分别标注有来源、推测、新增设定、未知和手动改写。引用校验只验证原文存在，不能保证模型解释正确。
- 生成结果先进入草稿，可修改分类和任意字段、增删属性。重新检索保留手动改写、已采用新增设定及已删除字段。先「预览改写」再确认应用；模拟演变和采用建议也只改变草稿。
- 应用后的设定保存在当前聊天元数据中，可查看历史版本并加载为回滚草稿。每轮正常聊天生成使用独立提醒；未知和推测不会作为确定事实注入。可选择一直成立的设定重构或从当前时刻生效。它通过提示影响后续故事，不改写已有聊天文本。聊天分支变化会排除不属于当前分支的记录。
- 「检索设置」可以关闭剧情提醒、调整长度并预览内容。联网搜索使用 Tavily Search 格式接口，可填写兼容代理地址和密钥；密钥只在当前页面内存中，刷新需重填，不写入聊天或 AI 预设。外部检索只发送目标或用户填写的搜索词；选取的资料交由 OS 共享 AI 整理。

联网模式需配置搜索服务密钥，模型 API 密钥不能替代搜索密钥。浏览器跨域策略不允许直连时需兼容代理；失败会明确报错，不伪装成成功搜索。接口格式参考 [Tavily Search 官方文档](https://docs.tavily.com/documentation/api-reference/endpoint/search)。真实酒馆、真实模型与实际联网搜索尚需用户环境验证。

## 0.4.1 楼层回复选项与统一控件

修正磁贴编辑栏下拉框与按钮的主题配色，避免宿主暗色控件样式覆盖。消息楼层新增回复选项按钮，与地图、状态按钮共用原有样式和对齐设置。

设置 → 楼层窗口新增三个按钮的显示开关，由 OS 统一管理；关闭开关会收起对应已打开窗口。回复窗口沿用统一宽高、圆角与主题，也可单独设置尺寸。窗口按每条消息内的打开顺序从上到下排列；关闭再打开会排在末尾，按钮顺序始终为地图、状态、回复选项。

楼层回复选项复用共享 AI 设置和草稿保护，参考到指定楼层为止的聊天，生成候选后填入当前输入框，不自动发送。多个楼层使用独立窗口，关闭时取消等待并移除监听。旧楼层内容被替换或聊天切换时清理旧窗口。世界书与角色设定仍使用当前配置，不恢复历史版本。

已在模拟宿主中验证生成、填入、撤销、窗口打开顺序、关闭重开、显示开关与 390px 手机排版；真实酒馆与实际模型仍需更新后试用。

## 0.4.0 Metro 磁贴开始屏

首页采用 Windows Phone 风格的直角磁贴：小、中、宽三种尺寸，四列网格自动排布。地图默认宽磁贴，世界状态和回复选项默认中磁贴，AI 设置和设置默认小磁贴。配色跟随全局主题，Courgette 品牌名称保留。

点击“编辑布局”或长按约 450ms 进入编辑模式；拖到另一块磁贴上松手即可插入排序，目标磁贴显示虚线提示。编辑时点击磁贴选中它，在上方切换尺寸；也可使用前移/后移按钮或方向键排序。点击“完成”后恢复点击打开应用。设置 → 整体外观 → 恢复磁贴默认布局可恢复初始顺序及尺寸。

布局保存于当前浏览器/设备的本地存储，刷新后保留，不跨设备同步。进入应用显示返回键和当前应用名称。此版本改造开始屏与导航，应用内部表单和楼层窗口沿用原有设置；尚未加入动态信息磁贴。

验证：浏览器鼠标拖动、尺寸切换、刷新恢复、默认布局重置与应用返回已通过；390px 窄屏无横向溢出。已实现触屏长按/拖动处理，但尚未在真实手机上验证触屏手势。

## 0.3.0 统一外观设置

保存立即更新已打开的界面及状态 iframe，不重新创建编辑表单。样式仍限定在 Amin os、其地图窗口和状态楼层组件内，不更改酒馆主界面。

## 安装

1. 在扩展管理中停用原来的动态地图、世界状态栏、回复选项三个插件，然后刷新。无需删除原文件。
2. 在酒馆“扩展 → 安装扩展”中填写 `https://github.com/agentgeleven-lab/amin-os`。分支留空或填写 `main`。
3. 启用后刷新页面，点击右下角入口。

也可手动解压安装包，将整个 `amin-os` 文件夹放入酒馆实际用户扩展目录，例如 `data/default-user/extensions/amin-os/`。TauriTavern 使用它实际数据目录下的用户扩展目录。确保 `manifest.json` 直接位于 `amin-os` 内。不要把 ZIP 文件路径填入“从 Git 仓库安装”。纯 JavaScript，无需打包或安装依赖。

检测到旧版已加载时，Amin os 会提示先停用。不要同时启用三个旧插件：它们会重复监听聊天、注册工具、管理输入框和写入相同数据。此版本保留原数据键以继续使用已有内容，不会批量迁移或清空旧数据。卸载回退时停用 Amin os、刷新，再启用原来的三个插件即可；注意运行期间保存的数据会继续保留。

## 五个应用

- **设置**：OS 统一外观、单应用覆盖、桌面和手机楼层窗口尺寸。

- **AI 设置**：全局 API 连接、命名配置库、输出长度、超时、串行/并行、流式接收；统一异步生成预设和任务取消、实际提示词预览。配置保存对下一次生成生效，已提交任务保留快照。

- **地图**：节点/六边形/方格、多层地图、编辑草稿、手动保存、AI 生成、工具调用/正文更新、模板和导入导出。未保存草稿不会成为正式地图。原有消息末尾入口仍可按应用设置保留或关闭。
- **世界状态**：变量编辑、生成/更新、全体与角色规则、模板、备份、楼层记录、世界书同步、主题。编辑器嵌入侧栏，切换应用保留表单；切换聊天清除旧编辑器并重新读取。设置页接入地图位置入口。
- **回复选项**：按聊天生成候选、草稿扩写、人称/方向/数量等设置、候选切换、撤销和手动编辑保护。点击只填入宿主聊天输入框，由用户发送。

## 数据与兼容边界

地图继续使用当前聊天 `dynamicMapV1` 与原浏览器命名空间；状态继续使用聊天变量“状态栏”、原历史和规则配置；回复选项继续使用 `reply_options_mvp` 设置。Amin os 记录入口位置和按用户命名空间隔离的共享 AI 配置、API 配置库、预设与当前选择。密钥默认仅当前页面会话有效，勾选记住后存于本浏览器。

三个应用的生成统一读取 AI 设置，默认使用酒馆当前连接。旧配置保留；通过“导入原地图 / 状态栏配置”复制到共享库，再手动选择并应用。原状态栏会话密钥需重新填写。配置选择和预设均为全局，不再按应用分别指定。状态应用仍只支持单角色聊天；地图和回复选项按原功能处理群聊。世界书和小白 X 联动的原限制仍适用。Amin os 不包含小白 OS 的内核或数据库，不要求安装小白 OS。

地图生成默认先进入草稿；关闭整个侧栏不会主动取消正在运行的生成。需要中止时使用对应应用的取消按钮。宿主模型的“停止等待”不能保证终止底层请求。

## 共享生成设置

打开 Amin os → AI 设置，在“API 连接”保存并应用到全部应用；在“异步预设”选择或编辑提示词块，编辑后保存。三个应用提供可用的角色卡、世界书和近期聊天，地图额外提供地图草稿。“本次要求”必须启用；各应用的输出协议和结果验证始终保留。未提供的资料块会跳过。已有地图预设可导入，移除资料块会影响模型可见的上下文。

“任务记录”显示本页最近任务并可取消，展开可检查实际消息内容。请求由浏览器直接发出，独立 API 需支持 Chat Completions 和跨域。串行模式覆盖三个应用；取消酒馆请求只停止等待并丢弃晚到结果，底层请求结束后才释放队列。切换为并行仅影响新提交任务。

这里统一的是三个应用主动发起的生成、追加、更新、扩写请求。酒馆主聊天回复，以及随主回复执行的工具调用/正文解析，继续由酒馆模型驱动。共享配置不会更换酒馆主聊天模型。没有新增自动定时运行器。

## 本地交互预览与开发

安装 Node.js 后，在此目录运行 `node scripts/preview.mjs`，打开终端显示的本机地址。只使用演示数据和模拟回复，不需 API 密钥。关闭终端可结束预览。预览服务器只监听 `127.0.0.1`。

`npm run check` 进行静态检查，`npm test` 运行自动测试。

入口是 `index.js`；统一窗口为 `shell.js`、`window-state.js`、`style.css`。统一外观状态、界面和楼层样式位于 `settings/`；共享生成服务和 AI 设置界面位于 `ai/`。三个内容应用分别位于 `apps/map`、`apps/status`、`apps/reply`。应用的原说明保存在各自目录内，其中独立安装和独立启动方式以本说明为准。

源码基线：动态地图 0.15.0 / a72c501；世界状态栏 1.11.5 / 531f9b3；回复选项 0.2.5 / 5c11fcd。保留原业务模块，改造应用挂载和统一窗口入口。
