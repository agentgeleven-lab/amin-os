# 人物关系

人物关系继续使用现有应用入口。关系方向、人物引用及强度都由已确认的数据决定；同名人物不会自动合并，反向关系不会自动建立。

## 按剧情更新

在“根据剧情提出关系更新”中选择起止楼层（界面从 1 开始），填写可选要求，再点击“分析所选剧情”。一次最多 30 楼、所选正文最多 60000 字。渠道在 AI 设置中的“人物关系”配置，使用共享 AI 的 `capture('relationships')` 和 `generate('人物关系 · 剧情更新', ...)`。

建议使用统一更新格式：

```json
{
  "version": 1,
  "changes": [
    {
      "module": "relationships",
      "action": "save",
      "target": "trust_alice_bob",
      "data": {
        "fromId": "alice",
        "toId": "bob",
        "type": "信任",
        "label": "愿意合作",
        "notes": "双方明确同意互相支援",
        "sources": [12]
      },
      "reason": "第 13 楼双方已经达成支援约定。"
    }
  ]
}
```

`save` 提交完整关系；不填 `strength` 表示没有数值强度。模型不会被要求自创统一好感量表。应用内 AI 分析只允许 `save` 和 `delete`，每个关系最多一条最终建议，来源必须在选定范围内。所有建议先完成校验、再形成一份预览，确认后一次保存。任何一项无效时都不写入当前资料。

源楼层的正文、候选、聊天或相关人物资料变化会使建议过期。保存失败时使用“重试保存”，不会重新执行变更或重复产生阈值提醒。可在关系列表展开“更新依据与来源”查看确认原因和保存时的原文。

## 阈值提醒

在“关系阈值与提醒记录”中配置所属关系、`≥`/`≤`、数值、提示语、启用状态和提醒频率。规则绑定关系 ID，不绑定显示名称。

- 只有旧值和新值都记录了有限数值强度，且由条件外进入条件内，才触发提醒。
- 新增或修改规则时，不补发当前已经满足的条件。
- “同一规则只提醒一次”以规则的关系、比较符、数值、提示语和频率组合去重。修改这些条件相当于新的规则定义；停用后重新启用不会重置既有提醒。
- “每次重新跨越阈值时提醒”需要先离开条件范围，再重新进入；持续处于满足条件的范围不会反复提醒。
- 提醒只是提示，不会生成剧情事件、修改他人的记忆或自动建立反向关系。可预览标记已读，保留历史记录。
- 删除关系不删除其规则和既有提醒；未解析的旧引用保持可见，规则不会按同名关系重新绑定。

## 统一联动

`apps/linkage/adapters/relationships.js` 提供纯数据适配器。除关系 `save/delete` 外，统一更新支持用户明确要求的 `save-rule/delete-rule/acknowledge-alert`；完整约束由 `updates.js` 的 `UPDATE_CONTRACT` 提供。规则操作仍必须经过统一权限、校验与确认/自动应用策略。

适配器只返回 patch，不保存 metadata、不调用 AI、不生成随机数，也不修改原上下文。阈值提醒跟关系变更处于同一个原子提交内。统一联动接管关系模块时，旧的单独关系正文注入暂停，避免重复提供同一份上下文。

精确来源正文存入本地历史。送入模型的关系状态只带来源索引、原因和来源是否仍匹配，避免重复注入整段历史正文。

## 数据与兼容

继续使用 `amin_os_relationships_v1`，事件保存于当前分支路径：

- 关系的可选 `evidence`：`{origin, reason, sources:[{index,revision}]}`。
- 快照的可选 `thresholdRules`、`thresholdAlerts`。
- 事件的可选 `evidence`，新增操作类型 `rules/alerts/ai/linkage`。
- 旧快照和未填写依据的旧手动操作保留原对象形状，不强制补充新字段。
- 恢复存档通过 `validateState` / `buildRestore` 保留新增数据，在当前楼层追加快照。

人物卡跳转：打开 `relationships` 后，在 `document` 派发 `CustomEvent('amin:select-character', {detail:{app:'relationships',characterId}})`。关系窗口会按稳定人物 ID 聚焦。


### 关系地图

- 分层地图按连接远近排布，保留循环、双向关系，不推断亲属或辈分；圆环布局可随时切换。
- 聚焦人物时保持人物位置，淡化其他人物，突出直接关系；关系文字在独立说明区与可点选关系按钮中显示。
- 支持缩放、查看全图和框内滚动；手机默认先显示列表，可展开地图。
- 地图最多显示 128 人，超出时显示数量提示并保留当前聚焦人物；完整关系列表不受此上限影响。
