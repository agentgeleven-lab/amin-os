# 语音朗读

## 当前界面与历史音频（0.12.0）

语音应用分为「朗读与分段」「声音设置」「音频库」。支持 MiMo 直连、火山引擎、本地 Azuma Bert-VITS2 及 MiMo → 本地 DXL1。选择引擎后只显示适用参数，对话与旁白分别调整；切换分页保留编辑内容，切换两个本地引擎也会保留各自尚未保存的服务地址。点击「保存设置」或主动生成时保存参数。

OS 输入页可朗读自行填写的正文；楼层窗口只读取该层正则处理后的可见文本。主要生成按钮在朗读页，暂停、继续、停止和失败重试在各分页均可操作。

「音频库」默认显示当前输入／当前楼层的记录。在 OS 的语音应用中勾选 **「全部本机历史」**，可查看同一浏览器音频库中其他聊天及旧版本的录音，按最近保存时间排列，显示原来源与保存日期。每条可重听、下载或删除；重听直接使用保存的音频，不再次请求接口。跨来源录音隐藏重新生成按钮。楼层窗口不提供全部历史开关，继续只显示和控制自己的来源。

新的楼层音频来源包含保存到消息上的稳定标识和正文／回复版本摘要，数字楼层重新排列不会把音频关联到另一条消息。编辑正文或切换回复会形成不同来源。旧版按数字楼层保存的录音仍留在本机音频库，可以通过「全部本机历史」找回；不自动猜测它属于哪条当前消息。主应用明确点击旧录音的“重听”后，播放和暂停／停止沿用该录音的原来源，不给当前楼层绑定旧音频。

本机音频库来自当前浏览器的 IndexedDB 和当前页面内存，不等同于跨设备同步或备份。持久存储不可用时，当前页面新生成的音频可能只留在内存；保留现有保存状态提示。下面保留各引擎接入与历史功能说明。

开发回归覆盖音频来源隔离、全部历史的持久记录与内存合并、旧音频重听及楼层控制隔离。离线测试不证明真实语音提供方、酒馆宿主或手机音频播放已通过验证。

## 本地东雪莲接入（原始功能）

模型固定为 Azuma Bert-VITS2 2.3，东雪莲，G_18200.pth。插件本身不包含模型和 Python 环境。

1. 启动你的本地模型服务（现有“启动试听.cmd”）。
2. 在 Amin os 编辑布局中添加“语音朗读”磁贴，或打开楼层的“语音朗读”按钮。
3. 检查连接，检查/编辑待朗读文字，然后播放。不会自动朗读新消息，也不会修改正文。

接口：GET /health 返回 app=azuma-bert-vits2、ready=true、version=2.3、weights=G_18200.pth；POST /api/generate 接收 text、speed、seed，返回 audio/wav。仅连接本机 localhost/127.0.0.1。手机连接的是手机自身，不会自动访问电脑模型。

默认 speed=1、seed=42、音量=1；语速范围 0.7–1.3。服务端保持 sdp_ratio=0.2、noise_scale=0.6、noise_scale_w=0.8、length_scale=1/speed。只适配中文。长文本按标点分段，每段最多 220 字符，串行合成与播放。

服务必须允许酒馆来源跨域访问。现有 FastAPI 服务可添加 CORSMiddleware，明确允许 http://tauri.localhost、https://tauri.localhost、tauri://localhost 和本机 localhost/127.0.0.1 的酒馆端口，允许 GET、POST、Content-Type；继续仅监听 127.0.0.1，不需要开放公网。

停止会终止客户端等待并丢弃旧音频；已经在 GPU 内执行的单段推理可能仍会完成。收起窗口不打断朗读；切换聊天、编辑/删除/切换消息停止当前播放。浏览器阻止自动播放时点击“继续”。楼层仅读取酒馆显示正则处理后的可见正文，排除隐藏节点和交互控件，不回退到原始消息。播放前检查渲染结果是否更新，仍可手动编辑待朗读文字。

## 对话与旁白（0.8.31）
默认识别中文弯引号、直双引号、「」和『』，支持嵌套。未闭合引号按旁白保留，不会丢弃原文。可在语音设置中按每行一对符号调整规则；分类预览可逐段改为对话或旁白。修改正文或引号规则会重新识别，清除本次手动分类。

朗读范围可选全部、仅对话、仅旁白；全部保留原文顺序。两类分别设置语速（0.7～1.3）、音量（0～100%）、段后停顿（0～5000 毫秒），仍使用同一东雪莲模型。旧版语速和音量作为两类初始值。参数全局保存并用于之后的朗读；已打开窗口保留其当前编辑值。停顿不包含下一段合成时间，停顿期间可停止。

## MiMo → DXL1（0.8.32）
在语音设置选择 MiMo → DXL1，引擎地址为 http://127.0.0.1:9884。先启动本机 mimo-rvc-studio，在其网页中设置 MiMo 密钥；密钥仅保留在服务内存，重启后重新填写，不保存到 Amin os。

选择索引比例 0.5 或 0.75（初始值 0.5，并非音质评判）。DXL1 来自 lowo/RVC-weights，角色与原作者未确认。转换在本机执行，MiMo 接收待朗读正文和声音描述并产生调用费用。两类可选日常、温柔、开心、小吐槽情绪，共用基础声线；留空使用试听台默认描述。MiMo 的语速通过播放器播放速率调整并保持音高。

本机服务须为已更新 DXL1 版本：GET /health 报告 rvc_model=DXL1.pth；GET /api/session 返回本机会话令牌和默认声线；POST /api/generate 创建任务；GET /api/jobs/{id} 查询，结果须包括 model 和 ratio；POST /api/jobs/{id}/cancel 请求取消。写请求带 X-Local-Token，服务明确允许酒馆本地来源跨域访问。RVC/模型不随插件分发。

停止不保证中断已经提交给 MiMo 的计费请求或正在执行的 GPU 推理，但会取消后续步骤、丢弃旧结果且不播放。分段串行执行，不连续读取别的楼层。

## 插件直连合成（0.8.33）
选择“MiMo · 插件内合成”或“火山引擎 · 插件内合成”，不需要启动 9883 / 9884。密钥在插件的密码框填写，随酒馆设置保存；不要公开包含密钥的设置文件。不会从旧试听服务自动提取密钥。

MiMo 使用官方 API Key、mimo-v2.5-tts-voicedesign；可编辑基础声线与对话/旁白的自由情绪描述。火山使用语音控制台 App ID / Access Token（不是 AK/SK），填写已开通的资源 ID 和音色 ID；情绪代码仅适用于支持该情绪的音色，2.0 音色不保证支持 emotion，留空使用原声线。本版本火山不提供文字创建新音色。新版 X-Api-Key 未出现在实测跨域允许头中，插件采用 App ID / Access Token 路径。

音量支持 0～200%，使用 Web Audio 增益；超过100%可能使高峰声音失真，按实际听感调整。音量不改变云端请求原文。旧版声线、正则过滤、本层范围及分段顺序保留。DXL1 仍是可选的本地引擎，需要原来的运行环境；纯云端模式不经过 DXL1。

“检查配置”只检查必填项，不产生合成请求；点击播放才验证鉴权与实际合成。MiMo / 火山请求直接发送官方端点，不经外部试听台。浏览器跨域支持取决于服务端策略。

接口依据：[MiMo 合成文档](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)、[火山 V3 文档](https://www.volcengine.com/docs/6561/1598757)、[字节官方请求示例](https://github.com/bytedance/agentkit-samples/blob/main/skills/byted-text-to-speech/scripts/text_to_speech.py)。

## 0.8.35 MiMo 语速与情绪
MiMo 直连与 DXL1 的播放倍速范围为 0.7～2.0，保持音高；其他引擎保持 0.7～1.3。18 个情绪预设与自定义文本分别用于对话/旁白。旧 DXL1 服务的新情绪写入基础声线提示词并标记优先级，不需重启；情绪表现取决于模型实际生成。

## 0.8.36 失败段落重试
生成或播放失败时保留队列与原始设置，点击“重试失败段落”从失败段重新生成，成功后继续后面的段落。已完成段落不重复合成。手动重试可能再次产生该段的 API 费用，不自动无限重试。停止、消息变更、切换聊天或新的朗读清除旧队列；刷新页面不保留进度。

## 0.8.37 段落选择与音频库
分类预览按对话/旁白、换行及 220 字上限拆分，与实际请求单位对应。勾选与朗读范围共同决定启用段落。仅生成按钮不自动播放；生成并朗读会生成所有勾选段。生成的语音保存在当前酒馆来源的 IndexedDB，楼层之间隔离；独立语音应用使用单独的共用列表。刷新后可恢复音频，清除网站数据或更换浏览器不会保留。API 凭据不写入音频库。
重听使用已保存音频和原播放参数；重新生成使用当前语音设置，仅成功后替换该段音频，失败保留旧音频。下载和删除可管理本机空间；数据库写入失败时会提示仅本次运行保留。分类勾选为当前编辑状态，重新解析正文时重置。

## 0.8.38 安卓远程 DXL1
选择 MiMo → 本地 DXL1，勾选连接远程电脑，输入 HTTPS 服务域名和专用访问密钥。手机不会启动 Windows 本地服务，需电脑运行 DXL1、认证网关及隧道。密钥随插件设置保存，不要公开设置备份。远程管理页面不开放，MiMo 密钥仍在电脑试听台设置。

## 0.8.39 批量并发
批量生成勾选段落：云端最多 3 路。新版 DXL1 服务返回 batch_concurrency=3，MiMo 请求并行、共享 RVC 模型由互斥锁保护；旧服务保持串行兼容。生成并朗读仍按顺序逐段播放。失败段落不阻止其余任务，重试只重新生成失败段落。实际速度取决于 API 限流、网络和显卡；不保证三倍速度。
