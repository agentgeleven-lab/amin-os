# 文风转换（stylewriter）

把输入框里的原文改写成目标文风的独立应用，接入 Amin os 启动器与共享 AI 设置。

- 两种模式：**参考当前聊天文风**（仅读取当前已加载聊天最近 16 条非系统正文：每条完整传递、更早消息按条数不包含；不读取世界书 / 人设 / 群组设定）与**自定义文风**（请求中不包含任何聊天内容）。
- 自定义文风预设：命名保存、下拉选择、修改与删除（删除确认绑定具体预设，切走自动解除；删除可撤销，未保存编辑随撤销一起恢复）；预设保存在酒馆 `extensionSettings`（本机），名称做长度 / 重名校验，名称与文风说明做密钥形状校验（文风说明不限长度、永不自动删减），绝不保存 API 密钥。
- 结果预览可编辑、可复制、可主动填回 `#send_textarea`：填回只写入草稿并触发 `input` 事件，绝不发送。
- 原文与结果按聊天身份隔离保存，不跨聊天显示；收起 / 隐藏面板不会清除未保存的预设草稿。

## 安全与正确性

- 每次请求先捕获共享 AI 快照（渠道 / 预设 / 限额）与聊天身份（chat / 角色 / 群聊 / `chatMetadata` 对象引用：metadata 被宿主替换即视为新聊天，其内部字段编辑不影响身份）、原文修订号、模式与预设快照；转换与读取输入前都会重新对齐当前聊天。
- 取消、切换聊天（含未发事件的上下文替换）、修改原文（输入 / 清空 / 重新读取）或编辑当前选中预设后，迟到结果一律丢弃，不会误应用。
- 填回授权只随成功应用的结果发放：新请求进行期间禁止填回 / 撤销，失败的重新转换不会让旧结果获得新授权。填回前比较输入框节点、原值与聊天身份；输入框草稿在转换后被编辑过则明确阻止填回并允许复制；结果区的手动编辑随聊天草稿一起保存。
- 转换经共享 AI 服务（`ai/service.js` 注册 `stylewriter` 应用，任务名「文风转换」）发起真实独立请求；`includeEffects` 关闭，不把角色扮演规则带进改写任务。
- 不修改聊天存档；群聊只作为读取当前聊天文本的来源。
- 预设保存走酒馆 `saveSettingsDebounced`：宿主同步报错时本次操作失败且列表不变；宿主返回失败 Promise 时列表与内存一起回滚到上次成功状态并提示，未保存的编辑保留在编辑器中（酒馆防抖保存通常无返回值，此处不做额外的持久化保证）。

## 文件

- `model.js`：预设校验与持久化、身份 / 内容戳、参考样本采集、填回守卫、请求组装（纯逻辑，可单测）。
- `generator.js`：共享 AI 适配器，复用回复选项应用的输入框保护（`inputElement` / `waitForResult`）。
- `view.js`：面板 UI 与全部异步防护。
- `scripts/browser-smoke.mjs`：无依赖 Edge/Chromium 冒烟测试（隔离 fixture，不调用真实模型、不动真实聊天）。

自定义模式开始转换前，请先保存文风预设或放弃尚未保存的修改；应用不会无视编辑器中的新文风而静默使用旧说明。修改原文或所用文风时，会取消正在等待的转换。
