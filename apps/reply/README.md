# 回复选项

Amin OS 内置应用，为当前聊天生成带方向标签的回复建议。入口为 OS 磁贴或消息楼层窗口；安装和更新统一通过 [Amin OS 主仓库](../../README.md)，无需安装独立版。

## 当前工作流

- **生成候选**：生成／换一批、根据草稿扩写（作者模式下为展开作者构想）、停止等待、选择候选、撤销填入。
- **设置**：创作模式、数量、长度、人称、方向、资料范围、文风和内容风格预设及其提示词。
- 选择只填入输入框，不自动发送。发送前可比较和改选；用户发送或切换聊天后清空临时候选。
- 候选不写入剧情存档。不提供保存候选、单项重抽、保留满意项或独立改写草稿。

具体步骤、预设编辑和楼层行为见 [使用说明](WRITING.md)。

## 提示词与资料

角色扮演模式拟写选定角色的对白或行动；创意写作模式生成作者层面的剧情推进构想。两种模式分别保存生成要求。仅选中的内容风格和文风参与生成；内容风格在应用任务要求中优先强调，仍不能保证模型完全遵循。

设置可控制近期聊天、人设、角色设定和世界书参考，预览本次资料并排除不需要的项目。楼层窗口的聊天范围截止当前楼层。世界书参考读取当前启用或绑定的书中未禁用的非空条目，不等同酒馆本轮关键词触发结果；大量资料可能超出模型上下文。

生成与草稿扩写共用回复选项 AI 渠道，详见 [AI 渠道](../../ai/CHANNELS.md)。文风不是另一次改写请求。模型结果会进行格式、数量和去重检查，语义与风格仍需核对。

## 操作保护

切换聊天、修改相关来源或设置会使旧候选失效。生成期间修改输入框会阻止陈旧扩写覆盖；手动编辑后换候选或撤销也会保护现有文字。超时或停止等待会丢弃迟到结果，但不能保证宿主或供应方已停止底层请求。

设置和预设库按现有扩展设置保存；窗口中的候选及未保存编辑属于临时内容。发送前如需另存文本，请自行复制。

## 开发与验证

在仓库根目录运行 `npm test`、`npm run check`。自动测试覆盖设置迁移、生成格式、上下文与预设、填入撤销、发送清空、候选失效和楼层边界。测试使用模拟宿主，真实模型遵循、TauriTavern 事件时序及手机操作仍需实际验收。

历史整合基线为 Reply Options 0.2.5（`5c11fcd`）；当前安装、界面和渠道说明以本页及主仓库为准。
