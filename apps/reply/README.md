# 回复选项 · Reply Options 0.2.5

根据当前聊天生成 2–6 个带方向标签的回复选项，点击填入输入框，由你编辑和发送。

## 安装与更新

酒馆 → 扩展 → 安装扩展，粘贴：

https://github.com/agentgeleven-lab/sillytavern-reply-options

已安装用户在扩展管理中更新后刷新页面。旧版数量、聊天条数和填入方式会保留。默认折叠的“回复选项”位于输入框上方。

手动安装：解压后将文件夹放入 `data/<用户标识>/extensions/`，确保 manifest.json 直接位于扩展目录内。不要同时保留两份插件。兼容前端使用其实际用户数据目录。

## 新功能

- **可配置上下文**：读取当前用户人设、当前角色或群聊成员的描述、性格与场景。“角色设定”同时读取角色卡主绑定和附加绑定的世界书；没有外部主绑定时读取卡内嵌世界书。可单独关闭。
- **激活的全体世界书**：每次生成重新读取当前全局启用，以及当前角色（群聊成员）、聊天、人设绑定的世界书。按书名去重，纳入所有未禁用的非空条目，不要求关键词触发；不读取未启用且无当前绑定的其他书。刷新或切换聊天后可以直接生成。状态栏显示实际读取的书和条目数量。
- **自定义生成**：数量、最近消息条数、回复长度、纯对白/混合/动作形式、方向列表、自定义要求。
- **叙述人称**：支持跟随上文、第一人称“我”、第二人称“你”、第三人称“名字”。默认跟随上文以保留旧行为。第三人称名字可自定义；留空时模型参考最近上文识别用户角色名字，无法识别时使用当前用户名称，不应使用对方角色名字。设置同时用于普通生成与草稿扩写。直接引语保持自然人称；纯对白不强加旁白。人称控制通过提示词传入模型，不对正文机械替换，仍受模型遵循能力影响。
- **方向标签**：默认推进剧情、追问细节、委婉拒绝、自由发挥；每行一个，可自行编辑。空行忽略，相同方向去重。方向少于选项数量时有放回随机抽取，允许重复；方向不少于数量时随机不重复抽取，数量相等则每个方向一次。方向为空时提示填写，不发送生成请求。每次生成重新抽取。卡片标签固定为抽取方向，正文通过提示词约束。模型必须返回恰好指定数量的有效不同回复，否则报错要求重新生成，不展示不足数量的结果。
- **草稿扩写**：先在输入框写草稿或意图，点击“根据草稿扩写”；候选替换原草稿，可撤销。生成过程中修改草稿会阻止过时扩写覆盖。
- **候选切换**：追加模式保留原草稿，选择其他候选只更换插件填入内容，不不断堆叠。替换模式也能还原原草稿。
- **撤销与保留编辑**：撤销恢复填入前内容；用户修改后不会强制覆盖，点“保留编辑”将当前内容作为下一次选择的基础。
- **紧凑界面**：默认折叠，记住展开状态。全部设置位于回复选项面板内部，默认完全隐藏，点击“设置”按钮才出现，再次点击隐藏，不再显示额外的设置折叠标题；设置较多时在内部滚动，不再占用酒馆扩展设置窗口。
- **生成恢复**：等待上限 15–300 秒，默认 90 秒；支持停止等待、忽略迟到结果和重试。可以解析 JSON 前后解释、代码块和已闭合 think 块，仍严格校验有效选项。

## 数据范围与限制

只使用当前酒馆 `generateRaw` 模型连接，不新增服务或密钥设置。聊天文本最多 24000 字符（单条末尾 4000），用户人设 4000，最多 8 个群聊成员的基本设定（每人最多 6000），扩写草稿最多 6000，自定义要求最多 4000 字符。

世界书读取覆盖全部当前群聊成员绑定，不受 8 人基本设定上限影响；全部未禁用的非空条目正文完整传入，不再设置 40 条、单条 1500 或合计 10000 字符截断。大世界书可能超出模型上下文，请按模型容量调整启用书或相关开关。

角色卡读取描述、性格、场景，不包含全部卡片字段或图片。未加载的精简角色对象可能没有完整设定。世界书直接读取文件中的条目正文，不执行条目中的宏或自动化，也不重新计算概率、递归、关键词、角色筛选等触发条件；这是整本启用书参考。禁用条目及空条目跳过。读取绑定配置或书文件失败会明确报错，避免误以为已包含。人设来源为空时状态栏会显示。

“停止等待”和超时仅释放本插件界面，无法保证停止底层请求；可能仍计费。底层请求未结束时再次生成可能受模型服务或酒馆并发限制。插件不会调用全局停止接口来打断其他生成。

选项不写入聊天记录，不执行 HTML、斜杠命令或发送操作。切换聊天、编辑消息等会使旧候选失效。输入框被手动编辑时，撤销和换候选会保护现有文字。设置变化会要求重新生成。

## 开发接口

- `collectContext(ctx, settings, world)`：复制聊天、人设、角色及已读取世界书；仅非世界书字段保持原长度限制。
- `generateOptions(ctx, settings, {draft, world, onContext, isCurrent})`：当前模型生成，返回 `Promise<Array<{label,text}>>`。
- `parseOptions(raw, count)`：支持字符串数组及带 label/text 的 options 对象，去空、去重、限制长度。
- `DraftSelection`：维护原草稿及最后填入结果，实现切换/撤销/编辑冲突保护。
- `waitForResult(promise, ms, signal)`：等待上限和丢弃结果支持。
- `index.js`：宿主 UI 与事件协调；`style.css`：命名空间内样式；`manifest.json`：入口。

新增 `world-context.js`：通过 `loadWorldInfo` 读取书，并通过宿主 `world-info.js` 的 `getWorldInfoSettings()` 获取全局选择和角色附加绑定；兼容前端也可提供 `ctx.worldInfoSettings`。读取过程中会在调用模型前再次确认聊天/设置未变。

使用 `SillyTavern.getContext()`，兼容 `eventTypes` / `event_types`。需要标准 `#send_form`、`#send_textarea` 和支持对象参数的 `generateRaw`。

## 验证

运行 `node --test reply-options.test.mjs`。16 项自动化测试覆盖设置迁移、上下文开关、JSON 容错、草稿扩写提示、候选切换与编辑保护、超时取消、真实 UI 处理函数的会话切换与重试，以及绑定范围、全体书去重、完整正文、禁用条目过滤和读取期间失效保护。另已通过 JavaScript 语法检查。

这些是模拟宿主验证，尚未在用户实际酒馆中验证界面布局、真实模型及宿主世界书读取。实机请检查：正常生成 → 换候选 → 撤销 → 手动改字 → 保护提示 → 草稿扩写 → 切换聊天 → 世界书书名范围与读取数量。

禁用/卸载后刷新页面即可。不会修改原有聊天、角色卡或世界书文件。
