# 能力面板

当前开发改动：分组与能力两级下拉选择，支持直接发动（无指定对象）。主窗口与消息楼层窗口同步使用此界面。

原「持续效果」应用的旧能力、生效记录、分支历史和规则快照继续保留。已有文字分组原名迁入分组列表；没有分组的能力归入“未分组”，不改写旧原文和历史事件。

## 日常使用

1. 在主窗口或消息楼层打开「能力面板」，先选“能力分组”，再在“选择能力”中选中一项。可用“全部分组”查找；切换选择不会发动能力。
2. 查看能力说明，确认使用者及发动方式：“对指定对象使用”需要填写目标；“直接发动（无指定对象）”隐藏目标栏，不要求目标，也不会自动填成使用者。点击“发动所选能力”，输入本次具体指令；可展开调整作用层面和持续条件。
3. 点击「确认发动」。效果保存后回到首页，后续剧情生成会使用持续提醒。
4. 首页显示当前选择的效果，可调整指令、暂停提醒、恢复提醒或解除。复杂的转让、分割仍在「生效中」页面管理。

发动不会自动发送一条聊天消息，也不会直接改写过去的剧情。暂停保留关系记录并停止注入该项提醒，不会强制改写模型对历史剧情的记忆；需要明确终止关系时使用解除。

## 添加能力与管理分组

「能力管理」可手动添加能力原文，也可刷新世界书列表，选择一本全局启用或绑定的世界书，再导入能力条目。手动能力的提醒规则留空时沿用能力原文。

每个能力可设置名称、图标、所属分组、显示开关、默认发动方式、默认指令、作用层面和持续条件。编辑时可选已有分组，或填写“新分组名称”同时创建分组。旧尺寸和配色字段仍保留兼容，但当前主要选择界面为下拉栏，不再铺开能力按钮。配色、字号、圆角与间距继承 Amin os，可在 OS 外观设置中覆盖该应用。

“管理分组”支持新建空分组、重命名及确认删除；分组名称为 1–40 字，不能重名。“未分组”不可删除或改名。删除分组只将能力移回“未分组”，不会删除能力或改写已生效的快照。能力管理同样提供分组／能力下拉栏，可编辑隐藏能力。原排列顺序保留为下拉顺序；隐藏能力不会解除已有效果。

分组与能力库跨角色、聊天共享；主窗口和各楼层各自保留当前选择。分组或能力消失时清空无效选择，不自动发动另一项能力。表单有未保存修改时阻止切换顶部分页；明确点击取消／返回才放弃编辑。保存失败保留编辑内容。

直接发动仍使用原有持续效果记录机制，需要使用者、作用层面和持续／解除条件。它不表示作用于所有人；瞬时效果请明确条件，结束后主动解除，不新增自动判定或自动发送。对指定对象使用的旧行为不变。

## AI 与原文

添加或编辑能力时，AI 编写提醒使用共享 API 和预设，读取当前能力原文、现有规则和补充要求。草稿单独显示，可编辑并采用，最后保存能力。取消、离开页面或聊天变化后不会应用迟到结果。不会修改原世界书，也不会自动替换已发动效果的规则快照。

## 共享能力库

完整能力副本（含来源、原文、提醒规则、按钮和默认操作）保存于全局 extensionSettings 的 amin_os_ability_library_v1。原世界书停用、解绑或删除后仍可发动，来源变化不会自动覆盖。

打开旧聊天的能力面板时自动收纳旧 skills；迁移指纹防止重复导入与旧版本覆盖后续编辑，同 ID 不同版本保留独立副本。保留旧聊天数据。不同聊天需分别打开一次，不扫描或批量改写未打开的聊天。已有生效记录独立保存规则快照，同一能力的新旧规则可同时生效且分别引用。

能力管理提供“删除能力”及应用内确认页，删除后从共享库移除，保存在“已删除能力”中，可恢复原文、规则和按钮布局。删除记录与迁移指纹防止旧副本自动重新出现。已发动效果仍可调整、分割、暂停及解除；分割读取效果自身快照，无需能力仍在库中。

## 持续记录与范围

记录仍使用聊天 metadata 的 amin_os_effects_v1。变更以当时聊天前缀的精确内容与回复分支为证据；删楼、编辑或换分支导致不匹配时，不再使用该分支的变更。重新生成不注入将被替换的最后一条角色消息上建立的效果。

普通聊天使用 GENERATION_AFTER_COMMANDS 与 setExtensionPrompt；Amin os 共用 AI 请求也加入当前记录。「提示预览」可设置开关和字符上限，超过上限会明确提示而不截断。原文快照和精确前缀会增加聊天文件体积。

能力发动、解除、死亡继承、权限胜负和重叠范围由用户确认，本版不自动判定。分割只采用明确列出的子范围，不推导集合差值。相同目标和完全相同层面不允许重复建立记录。

模拟界面与自动测试不替代真实酒馆/模型验证；模型表现仍受其能力与上下文预算影响。

## 楼层窗口与验证范围

楼层入口仍显示当前聊天的数据，不是历史楼层快照；与主窗口共享能力和生效记录。关闭楼层窗口会释放其本地编辑与监听，需保留的未保存内容请先保存或复制。

开发回归包括 `npm test`、`npm run check`、`node apps/effects/scripts/browser-smoke.mjs`。浏览器使用虚构聊天、设置和托管接口模拟，覆盖普通及托管挂载、多窗口、分组管理、两种发动方式、回滚、切聊保护及 390px 布局。没有调用真实模型，也不等同于真实 TauriTavern／安卓实机验收。
