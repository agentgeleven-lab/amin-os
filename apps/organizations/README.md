# 势力概览（0.10.2）

这是独立的资料应用，不恢复已卸载的沙盘/战争规则，也不读取旧 `factions` 数据。

## 入口与基本使用

- Amin OS 首页 → **所有应用 → 势力概览**。新默认布局有磁贴；已有自定义布局会保留，不强制增加磁贴，可从“所有应用”自行固定。
- 六页：总览、组织、联盟／阵营、地区、评估排行、生成与规则。
- 在“生成与规则”选择角色设定、最近 20 条已加载的非系统消息，以及当前已启用世界书的勾选列表，设置范围、详细度和三类规则。先保存规则，再生成。
- **是否读取世界书**默认勾选，控制所有按钮AI操作。开启时，“读取当前角色设定”一并读取角色绑定/附加书；手选书与自动绑定书去重。关闭时不读取任何世界书，但保留角色设定、剧情等来源及选书设置。
- 每次生成/补充、重新生成整套、按剧情更新（含单项）及评估都会重新获取世界书最新内容，不复用首次素材；通过无缓存读取接口获取正文。只读启用条目，不判断关键词、常驻、概率、递归等激活策略。不会修改原世界书设置。
- 手选列表只显示当前启用书（全局、角色、聊天及人格绑定等实际来源），不是整个书库；可点击刷新。角色自动读取书有标记。旧名单中的失效选择会提示，取消选择或重新启用后再读取。群聊成员绑定书供手动选择，不自动指定唯一角色。
- **生成／补充**：添加主体、补充空字段，不替换已有非空资料。
- **重新生成整套**：重新整理所选类别；仍受字段锁定和引用完整性保护，不会强行覆盖锁定字段。
- **按当前剧情更新**：更新已有主体；默认不新增主体。组织／联盟／地区卡片还提供单项剧情更新。
- 上述 AI 操作以及手动资料修改、删除，均先展示变更预览；只有“确认应用”才写入。确认只消费一次，放弃不写入。
- AI 使用 Amin OS 全局 API 设置中的“势力概览”绑定与全局预设，不依赖小白X。请求开始时固定渠道配置，聊天/楼层变化或取消后不接受迟到结果。

## 资料结构

当前聊天变量的唯一资料根是 **`势力资料`**，JSON `version: 1`，包含 `organizations`、`alliances`、`regions` 三张以稳定 ID 为键的表。名称可以修改，关联仍使用 ID。

- 组织：背景、领导结构、理念目标、能力、当前状态、正在发生的事、组织关系等。
- 联盟／阵营：成员组织、共同目标、治理、义务、共同资源、内部矛盾等。
- 地区：人口、经济、基础设施、社会、安全、上级地区、控制／经营组织等。
- 指标为自定义列表，可记录明确数值、范围、文本或未知。没有预填战力、人口等评分；未知不换算成 0。
- 明确数值排行榜只比较同一指标 key、相同单位的 `number`；范围、未知、文本、单位不一致均排除并列出原因。
- 删除主体会预览其关联清理；禁止悬空关联和地区父级循环。

## 用户专用评估

AI 评估、比较与排行保存在当前聊天 metadata，而不放进模型默认剧情变量根。每份评估保存资料依据；资料或楼层变化后会显示过时提示。没有通用默认战力权重；评估规则由用户选择。

## 小白X变量管理2.0（可选）

1. 在当前聊天启用小白X变量管理 2.0。
2. 在“生成与规则”勾选日常联动，保存设置。
3. 点击“同步已保存规则到世界书”；只维护角色卡所绑定主世界书中本应用拥有的条目。也可复制提示词自行配置。
4. 修改锁定项、更新规则或关闭联动后，重新同步；关闭同步会禁用本应用条目。仅改设置不会擅自改用户世界书。

使用 `<state>` 的完整叶子路径，例如：

```text
<state>
势力资料.organizations.id_example.status: "暂时休战"
</state>
```

`id_example` 必须替换为已存在的实际 ID。不要使用旧 `[FACTION_UPDATE]` 块；不要用不完整对象替换整份资料。按钮写入会同步小白X全局变量/规则检查点，保留其他变量根。

锁定保护由代码校验，不仅是提示词；日常外部写入触碰锁定时拒绝该次资料变更。手动编辑允许用户明确调整锁定字段。外部变量结构不合法时显示错误，不静默重建为空数据。

## 历史与保存

- 楼层历史只读；删除末尾消息或切换 swipe 时恢复对应记录/上一楼，不借用未来状态。没有可恢复历史时清空该资料状态。
- 聊天、角色、metadata 对象、楼层内容或锁定变化后，旧预览不能确认。
- 写入后保存失败会明确提示“已写入内存”；请留在该聊天点击“重试保存”，不要重复应用。
- 群聊支持独立资料与历史，但自动写入“角色绑定主世界书”不支持群聊；可自行配置提示词。
- 不设置素材或完整请求的字符数上限；选定内容完整传递，不截断、不自动删减。模型/API仍有自身的上下文及请求体限制，超出时显示服务端错误；不自动裁剪重试，不修改用户的共享AI参数。AI返回不完整JSON时仍拒绝写入。

## 验证与边界

- `npm test`：模型、存储、AI、所有权、取消/隔离/回退及既有应用回归。
- `node apps/organizations/scripts/browser-smoke.mjs`：使用系统 Edge 的隔离浏览器，在真实 DOM 与共用 UI 样式下检查切页、重复挂载、编辑/预览/确认/放弃、评估、规则、历史只读及 390px 视口。可用 `AMIN_BROWSER` 指定 Chromium 路径，`AMIN_SCREENSHOT` 指定截图路径。
- 设置 `AMIN_LWB_PATH` 后运行 `node apps/organizations/scripts/lwb-smoke.mjs`：读取安装的小白X实际执行器，使用隔离宿主/聊天数据验证 `<state>`、数组关联、检查点与重放；不会改动真实聊天或小白X文件。

这两类冒烟测试不等于已经在用户实际 TauriTavern 会话中调用过真实模型、保存过真实世界书。宿主实际 API 网络请求、真实聊天刷新后持久化及日常模型输出仍需安装后现场确认。
